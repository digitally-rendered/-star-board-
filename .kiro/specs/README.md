# Specs

One spec per subsystem; `MASTER_SEQUENCING.md` owns phase order; `handoff.json` mirrors the tracker. Specs:

- `00-workspace` — Workspace
- `01-core-contract-registry` — Core: component contract and registry
- `02-spec-feature-model` — Spec: OpenAPI document to FeatureModel
- `03-tokens-theme` — Tokens and theme
- `04-runtime-hooks-client` — Runtime: providers, client, hooks
- `05-renderer-mui` — Renderer: MUI
- `06-generator` — Generator
- `07-testing-parity` — Testing and parity
- `08-cli` — CLI and example
- `09-agent-affordance` — Agent affordance
- `10-figma-code-connect` — Figma adapter and Code Connect
- `11-storybook-visual` — Storybook and visual regression
- `12-examples-docs` — Platform rules, examples, docs
- `13-rules-backfill` — Rules backfill

Status columns mean spec readiness, never implementation state (`hexagonal-rules/specs/05`).
